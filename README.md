# 📦 Controle de Estoque em Excel

Projeto de **controle e análise de estoque desenvolvido em Excel**,
criado como projeto de portfólio para demonstrar conhecimentos em
organização de dados, fórmulas, tabelas, indicadores e visualização de
informações.

> **Observação:** todos os dados utilizados neste projeto são fictícios
> e foram criados exclusivamente para fins de demonstração.

------------------------------------------------------------------------

## 🎯 Objetivo

Desenvolver uma planilha simples e funcional capaz de acompanhar a
movimentação de produtos, calcular o estoque atual e sinalizar situações
que exigem atenção.

O projeto foi pensado para simular uma rotina de controle de estoque de
uma pequena operação, permitindo acompanhar:

-   cadastro de produtos;
-   estoque mínimo e máximo;
-   entradas de mercadorias;
-   saídas de mercadorias;
-   saldo atual;
-   alertas de reposição;
-   produtos com estoque elevado;
-   análise dos produtos com maior estoque e maior saída.

## 💡 Insights do projeto

A análise dos dados fictícios permite identificar situações como:

-   produtos com alto volume de saída precisam de acompanhamento mais
    frequente;
-   produtos abaixo do estoque mínimo podem gerar necessidade de
    reposição;
-   estoque acima do máximo pode representar capital parado;
-   comparar entradas e saídas ao longo do tempo ajuda a identificar
    períodos de maior movimentação;
-   o ranking de produtos facilita a priorização das análises.
